修补图标使用方法
  1. 先在小米主题商店下载一个主题。
  2. 在“选择待修补主题”中选择一个主题，模块会自动读取手机端主题索引。
  3. 创建或选择修补组；修补组与主题文件名无关，可以重复用于重新下载的主题。
  4. 在“待修补图标”中选择应用和 PNG 图标，将它们添加到当前修补组。
  5. 选择“仅补全缺失图标”或“覆盖同名图标”，再点击“修补主题”。
  6. 打开主题商店，在“我的／主题/”中应用该主题或混搭应用图标。

仅支持 PNG。模块会自动调整尺寸，确保每个新增图标不超过 50KB。写入异常时会自动回滚。

图标缝合使用方法
  1. 选择需要被修改的目标主题。
  2. 选择提供图标的源主题；源主题不会被修改。
  3. 新增图标默认选中，已有图标必须切换到“覆盖已有”后手动选择。
  4. 确认选择后执行缝合，再到主题商店应用目标主题。
