# HyperOS 图标补全器

面向 KernelSU WebUI 的 HyperOS／MIUI 主题图标工具，用于给主题补充自定义图标，或组合两个主题中的图标。

## 核心功能

| 功能 | 图标来源 | 写入目标 | 适用场景 |
| --- | --- | --- | --- |
| 修补图标 | 用户选择的 PNG | 已下载的主题 | 为主题补充未适配应用，或替换已有图标 |
| 图标缝合 | 另一个已下载的主题 | 目标主题 | 保留目标主题的整体风格，同时使用源主题中的部分图标 |

### 修补图标

自定义图标保存在可复用的“修补组”中，不与某一个主题文件绑定。主题重新下载或文件名变化后，仍可继续使用原修补组。

- 创建、重命名、复制和删除修补组。
- 从已安装的用户应用中选择 PNG 图标，自动按应用包名保存。
- 自动缩放 PNG，确保处理后的单个图标不超过 50KB。
- 支持两种修补方式：
  - **仅补全缺失图标**：保留主题已经提供的图标。
  - **覆盖同名图标**：使用修补组图标替换主题中的同名图标。

操作流程：选择目标主题 → 选择修补组 → 添加自定义图标 → 选择修补方式 → 修补主题。

### 图标缝合

从一个只读的源主题中选择图标，将它们新增或覆盖到另一个目标主题。

- 仅展示设备上已安装应用对应的主题图标，包含用户应用和系统应用。
- 双列对照目标主题与源主题的图标，并支持搜索、筛选和批量选择。
- 目标主题缺失的图标默认选中，可直接新增。
- 目标主题已有的图标默认不选中，必须由用户手动确认覆盖。
- 优先匹配相同 drawable 密度的源图标；源主题始终不会被修改。

操作流程：选择目标主题 → 选择源主题 → 勾选需要新增或覆盖的图标 → 确认并缝合。

## 安装与使用

1. 从 [Releases](https://github.com/ZeroHomers0/HyperOS-Icon-Patcher/releases) 下载模块 ZIP。
2. 在 KernelSU 管理器中选择本地安装并重启设备。
3. 在小米主题商店下载准备修改的主题。
4. 从模块详情页打开 WebUI，选择“修补图标”或“图标缝合”。
5. 操作完成后，在主题商店的“我的／主题”中应用主题，或通过混搭功能应用图标。

## 安全与数据

- 仅支持 Android ARM64，主题索引和写入由模块内置的 `hipzip-arm64` 在设备端完成。
- WebUI 只读取主题索引和按需预览，不传输完整 MRC。
- 写入前检查文件完整性和可用空间，写入后校验 SHA-256；异常时自动回滚。
- 生成和写入使用设备端互斥锁，避免重复操作或多个 WebUI 同时修改主题。
- 覆盖安装模块会保留修补组；明确卸载模块时会清除模块持久数据。
- 修补成功后不会长期保留整份主题备份。如需撤销，请重新下载原主题。

数据限制：最多 50 个修补组，每组最多 500 个图标，模块持久数据上限为 256MB。

## 兼容性说明

模块处理的是主题商店下载的 `.mrc` 图标主题，不支持修复或导出 MTZ。

不同 HyperOS 版本可能调整主题路径、缓存结构或刷新方式。如果无法识别已下载主题，请在反馈时附上脱敏后的设备信息和相关日志。

## 开发与测试

仓库根目录同时也是 KernelSU 模块根目录，`module.prop`、`customize.sh` 和 `uninstall.sh` 必须位于发布 ZIP 根目录。

常用检查命令：

```powershell
node tools/test-contract.mjs
go test ./...
bash -n customize.sh uninstall.sh scripts/*.sh tools/*.sh
bash tools/test-backend.sh
```

重新编译 Android ARM64 辅助工具：

```powershell
.\tools\build-hipzip.ps1
```

## Windows 打包

双击仓库根目录的 `pack-module.bat`，或运行：

```powershell
.\tools\pack-release.ps1
```

发布包默认生成到：

```text
output/HyperOS-Icon-Patcher-v版本号.zip
```

需要同时重新编译 ARM64 辅助工具时使用：

```powershell
.\tools\pack-release.ps1 -RebuildHelper
```

发布新版本时需同步更新 `module.prop`、`update.json` 和 `CHANGELOG.md`。标签使用 `vX.Y.Z`，附件名使用 `HyperOS-Icon-Patcher-vX.Y.Z.zip`。
