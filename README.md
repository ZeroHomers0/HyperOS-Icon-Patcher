# HyperOS 图标补全器

面向 KernelSU WebUI 的 HyperOS/MIUI 主题图标补全模块。

## 安装

1. 下载 Release 中的模块 ZIP。
2. 在 KernelSU 管理器中从本地安装。
3. 重启手机后，从模块详情页打开 WebUI。

仓库根目录即模块目录。打包时应确保 `module.prop` 位于 ZIP 根目录，不要额外套一层文件夹。

## 功能

- 仅列出用户安装应用，展示应用名称及当前图标
- 为应用选择 PNG，自动以包名命名
- 仅接受 PNG 输入，并校验 PNG 文件头
- 自动调整新增图标尺寸，确保单个文件不超过 50KB
- 在浏览器端修改 ZIP，避免依赖手机上的 `zip` 命令
- 扫描主题商店 `.data/content/icons/*.mrc` 源组件
- 按相同 UUID 匹配 `meta/icons/*.mrm`，优先读取 JSON 的 `titles.zh_CN`，并兼容 `description.xml`
- 在 WebUI 中刷新系统桌面，让新图标立即重新载入
- 使用兼容性分块传输加载选中的商店组件
- 备份并修改商店图标源，再由主题商店正式应用
- 一键恢复选中组件最近备份
- 跟随系统、浅色和深色三种 WebUI 外观
- 检测主题商店更新是否覆盖自定义组件
- 将自定义图标单独保存为合并配方
- 商店更新后以新版主题为基础重新合并；同包名冲突时主题新版优先

## 注意

小米不同 HyperOS 版本可能改变活动主题路径、图标目录或主题刷新方式。
如果状态页无法识别当前主题，请提交 `ls -laZ /data/system/theme` 的脱敏输出。

模块仅使用“主题商店图标源”工作流，不再读取临时活动主题，也不再修复或导出 MTZ。

无冲突时会保留主题新增图标和全部自定义图标；发生同包名冲突时不写入旧自定义图标。
